# Big G Derate Prediction

## Team Project

This project was completed as part of the Nashville Software School Data Science Apprenticeship.

## Project Goal

Develop machine learning models capable of predicting future truck derate events using J1939 fault and diagnostic telemetry data.

## My Contributions

- Exploratory Data Analysis (EDA)
- Feature Engineering
- Degradation-Dynamics Framework
- Instability and Recovery Behavior Analysis
- Random Forest Modeling
- XGBoost Modeling
- Time-Series Validation

## Key Insight

Operational degradation was better represented by evolving instability and shrinking recovery behavior than by isolated abnormal sensor readings.
